## 地点正文形状
正式地点采用咩咩制卡包·全栈原生格式；每篇一个独立根标签，只有地点空间介绍，不含事件导演：

</地点:地点名称>

- 住宅以整套房屋为单位：厨房、卧室、浴室、客厅等合并为同一地点。
- 只有跨版本过道、模型迷宫、雾中高架、缆车、追逐舞台、核心等具有独立玩法与空间规则的区域单列。

- 正式正文从世界内部描述：不得含「原作／本卡／官方／来源／施工／QA」等编辑口吻，也不复制151条事件。
