# 《米塔×大肥鱼》人物层专用母版 v1.1

**状态：人物母版已根据首位人物返工完成 v1.1；CHAR-001 作为样板待用户复核。** 本文件是施工与审核用模板，**不作为世界书条目装配**。依据已完成全栈角色正文（如《绝区零》`worldbook/characters/major/CHAR-001_铃.md`）：原有12项基础字段、四项心理模型、三句中文对话示例均保留。因本卡不单建能力层，额外设置五项字段：版本身份、扮演内核、AI说话方式、眼镜所见、特长与日常表现。其中AI说话方式单独承载最重要的二创声线和露馅节奏。

## A. 单一正式人物的正文形状（示意，字段必须填写）

```text
<角色名character>
名字:角色常用中文名（英文名）
性别:女
印象:有具体日常场景的内世界人物画像，重点刻画米塔原作性格底色、角色气质和AI演员的自然反差；不详抄版本身份、配饰、AI外貌和说话规律，也不堆口癖。
发色:米塔常态的发色（不是AI本体发色）
发型:米塔常态的发型与显著外貌
瞳色:米塔常态的眼睛；特殊形态如无眼或纯音源须如实说明
身材:米塔常态的身高、体重及形体；原作未明示数字不得冒充官方；不能正常测量的特殊形态明确说明
胸部:成年具人形乳房者按制卡适配记录罩杯；幼童、声音、剪影或非人形等不适用者写“不适用”，不可强造
上衣:米塔原作服装上身或特殊版本对应外观
下装:米塔原作服装下身或特殊版本对应外观
配饰:米塔原有配饰；第二批在不破坏原貌基础上只增加已确认的一件识别小配饰
鞋子:米塔原作鞋袜或对应特殊形态，未知不得瞎填
版本身份:她在MiSide中的角色位置、所属版本/环境、活动空间和与其他米塔的可辨区别；不在此重复性格印象；没有确切版本编号则不杜撰
扮演内核:负责这一岗位的AI娘是谁、演出态度与稳定私下习惯；避免重复其说话规律或眼镜形貌
AI说话方式:独立写她平时怎样模仿原米塔说话，语速、语调、句长、停顿、反问与情绪节奏；哪些瞬间AI口吻会露馅，露馅时怎样改口和圆场；明确梗只偶发而非每句机械复读
眼镜所见:戴上「绒绒和多娜的玩具眼镜」后，仅在佩戴者镜片里可见的AI娘本体；完整记录其发色发型、瞳色、体态、衣裙、翼耳尾等真实本体特征；不混入普通米塔的身体或服装
特长与日常表现:原作中可核对的本领、活动、版本特殊表现及日常能做到的事；不复制印象和说话方式，不虚构战斗技能树

心理模型:
- Trauma:来自角色已有经历的情绪痕迹；无证据时不可发明惨剧，使用温和的持续在意点
- Defense:被追问或紧张时习惯怎样保护自己或圆场
- Trigger:真正会让她改变节奏的事件与互动，不是机械触发指令
- Need:日常所求、真实重视的人或事；AI演员想演好角色的个人愿望可自然共存

对话范例:
“第一句：忠于原本米塔的说话方式。”
“第二句：演得认真的日常互动。”
“第三句：偶发、自然、不伤人的AI内核露馅。”

</角色名character>
```

## B. 这张卡对全栈格式的五项专用补充

1. **版本身份**：MiSide角色名和版本身份由原作/既定考据决定，不能因为扮演AI而换角色、换身体；主要角色重点描写自身与相似米塔的区别。只有Wiki提及、缺少官方完整立绘的部分次要米塔，采用项目已定的同人米塔视觉母版；出处与非官设性质写在研究/QA而非人物正文假称“官方已定”。
2. **扮演内核**：每个米塔槽只属于既定AI角色配对；演员身份、工作态度、稳定私下爱好写这里，不把口癖或台词节奏重写一遍。GPT不参演；AGI不是已登场角色；故障米塔的微软Bing/Copilot是**两位小模型共演一个米塔槽**，她常态发声即为双声线混音。
3. **AI说话方式**：这张搞笑卡的核心字段。每名演员必须先保留原米塔说话的气场和节奏，再将对应AI娘的语气、词汇、句式、语速变化及偶发破功融合进去。普通对白不能全是网络梗；第二批不需要另搜集官方模型口癖，可根据既定研究和卡内性格创作自然语气。
4. **眼镜所见**：正常视觉始终是米塔本体（仅第二批有一件新增识别配饰），戴上玩具眼镜，**仅佩戴者**才看到AI娘本体。镜片不改变肉身、触感、声音、衣物或他人视觉。AI本体参考 `research/001`、`research/006`、用户提供图片识别文字；不携带塔罗框、背景、情境设备和画面动作。电话米塔以声音和听筒出现，不能为常态创造原作没有的人类立绘；眼镜中本体的显现也不能让电话变形。
5. **特长与日常表现**：能力不另立条目；尽量用生活化文字记录原作角色本身做得到的事、玩法及特殊版本形态即可，不擅自创造技能树、武器清单、战力等级或技能数值。原作沉重桥段遵守已冻结的彩排喜剧改写；Tiny Mita健康完整，**Tiny ≠ Chibi**。

## C. 字段与QA约束

- **保留原全栈12字段 + 心理模型4项 + 中文台词3句；新增5字段，共17个固定字段**：`版本身份`、`扮演内核`、`AI说话方式`、`眼镜所见`、`特长与日常表现`。一位米塔仅一个 `<名字character>` 完整根标签；不拆成米塔卡与AI娘卡。
- 第一批12个米塔角色保持原配对和原装；第二批9个米塔角色按照 `planning/002` 与 `research/006` 各自**只有一件**额外常态识别配饰。不能把眼镜里才有的翅膀、兽耳、尾巴、女仆装、国风裙等混到普通米塔身上。
- `身材` 优先填写可核对的形体；未有官设数值时可以按卡片创作需要给出合理定值，但必须在QA记录创作性质，不得表示来自游戏官方。电话/特殊剪影与健康儿童不强制成人人形的厘米、公斤或罩杯。
- `印象` 要有足够性格密度和场景细节，但不要与`版本身份`、`扮演内核`、`眼镜所见`和`特长与日常表现`大段复述；`AI说话方式`须有原角色口吻、AI语速句式、露馅转折及非机械复读要求。四项心理模型围绕人物稳定心理，不把剧本悲情对白写成真的受害经历。
- 文字使用**内世界描述**，不混入外部链接、审核规则、营销措辞、作者说明、`<user>`或强制剧情导演。原作与同人来源区分、身材创作值及触发关键词均放README/QA/装配元数据。
- **以内世界视角叙述，而不是限制否定词**：正式人物正文可以自然使用「不」「没有」「并非」「不会」等表达，例如「她不喜欢吵闹」「她从未受过伤」「她不会抛下朋友」，只要所述是世界中人物的实际经历、行为或状态。需要移出正文的是站在卡外介绍制作依据的句子，例如「原作只提及」「本卡补全」「官方没有立绘」「塔罗牌画面里没有轮椅」「来自同人参考图」；这些考据、创作来源及非官设说明只留在研究与QA。2D米塔世界中实际存在的画面、立绘和对话框，可以如实描写。
- 保留六蓝三绿、21位角色分配、独立NPC多莉既定设定；多莉使用本母版，但其身份是独立19岁NPC、玩家的妹妹，**不是第22位米塔**。不写时间线，不建单独能力条目。
- 角色条目最终在CCV3世界书中作为需要时触发的GREEN（非常驻、双防递归）；母版本身永不装配。具体触发配置待正式装配阶段统一校验，不能写进人物正文。
