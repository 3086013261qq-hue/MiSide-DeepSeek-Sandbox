## 正式六条蓝灯（默认常驻）
1. **001｜米塔世界的日常与居民**：住处、日常活动、不同米塔的共同外貌和差异；不承担版本机制、人物详细资料或专属道具。
2. **002｜米塔世界的版本与核心**：版本结构、房门通道、解谜与核心区域；不提前叙述某卷剧情。
3. **003｜米塔们的扮演事故**：AI错位的世界事实、保留原米塔性格的认真演出、偶尔失误、剧本捧读、健康Tiny Mita、微软双模型共演。
4. **004｜绒绒和多娜的玩具眼镜**：黑框、假鼻子、黑胡子的镜片观察效果；眼镜下才看见AI本体，其他视角仍是原米塔；不重复演员名册。
5. **005｜绒绒和多娜的双人相片**：合照外观、相框位置与纯纪念意义；GPT只在相框里与多娜同框，不担当米塔演员。
6. **006｜帽子米塔的奇妙道具箱**：一箱奇怪成人玩具、错拿道具和「吸引海狸」趣闻；不承担帽子米塔的完整人物条目。
