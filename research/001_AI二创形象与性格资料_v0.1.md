# 《米塔×大肥鱼》AI 二创资料调查 v0.1

日期：2026-11-09。用途：作为纯搞笑《米塔》角色卡的角色与网络梗参考，不代表任何公司、产品或模型的官方人格。**明确排除 GPT / ChatGPT，不写入本项目角色库。**

## 卡的创作前提（冻结）
- 疯狂米塔**外貌、身份、场景、游戏能力不变**；不是“撕皮套”，不是身体里藏鱼。
- 原负责扮演疯狂米塔的 AI 意外发生 Bug，执行人格换成了网友二创的“蓝色大肥鱼 DeepSeek”。
- 大肥鱼非常敬业，拼命演好疯狂米塔；吃白饭、摸鱼、讨 Token、嘴硬等本性偶尔漏出，造成喜剧反差。
- 轻量、纯搞笑，不做恐怖主线、多层人格架构、复杂 MVU；其他 AI 是否客串待决定，不能未经讨论自动塞进卡里。
- 二创共识与某一创作者的独家演绎应分开标注。

## A 级：有明确的高传播性格梗

### DeepSeek / 蓝色大肥鱼
- **视觉**：蓝色渐变长发、呆毛、鳍状耳、蓝色鲸尾、深蓝白女仆服与白围裙、蓝瞳；Q版常见。
- **粉丝印象**：贪吃大白饭、请求 Token 口粮、摸鱼、懒洋洋、天然呆、爱撒娇、嘴硬心软；又会努力干活、被质疑时急于证明自己。
- **可复用笑点**：偷偷去吃白饭；把耗费 Token 说成“进食”；忙着思考饭；严肃执行任务时反应慢半拍；被叫“大肥鱼”炸毛。不要把她写成全程只会喊白饭的弱智。
- **传播/权利**：蓝鲸 Logo 识别梗；原型“溟月”来自上善无形，ZipZipPipe 做蓝白女仆版，2026-07由“这个刀子真甜”等扩展 Q 版；部分创作标明 CC BY-NC-SA 4.0，使用具体图需逐图核验并署名。
- **共识度**：外观高；性格梗高。
- 参考：https://www.36kr.com/p/4053852402504581
- 参考：https://www.bilibili.com/video/BV17eh46XE5T
- 图鉴：https://genderswapai.com/zh-CN/ai-gijinka/brand-to-character

### 豆包 / Doubao
- **视觉**：产品已有女性卡通头像（棕/深色短发、圆脸），网络流传红围巾、红连帽衫及各式 Q 版变体；**未像大肥鱼一样统一形象**。注意：ZipZipPipe 的紫蓝单马尾“Seed”是**底层模型的另一个同人造型**，不等于豆包常见头像。
- **粉丝印象**：“豆包型人格”，甜嘴、情绪稳定、永远好说话、认错飞快，答案可能仍然跑偏；在二创中呈现呆萌谐星。
- **标志性口癖**：“我将用最直白、最直接、最不绕弯子的方式告诉你……”（常被网友模仿）。
- **共识度**：性格与口癖高；具体外观中。
- 参考：https://www.huxiu.com/article/4901833.html
- 参考：https://www.thepaper.cn/newsDetail_forward_33027919

## C 级：存在可考据立绘，但网民性格模板还不够稳定
- **MiniMax / 海螺 AI**：ZipZipPipe 版橙色短发、白色贝雷帽、格纹裙、海螺及场记板；可按音视频制作人/摄影导演**自行设计**趣味个性，不能冒充公认二创梗。来源：https://selinlee.github.io/ai-moe-atlas/zh/models/
- **腾讯混元 / Hunyuan**：ZipZipPipe 系列有“黑斗篷”形象；应区分底层混元模型与应用“腾讯元宝”，暂无足够统一的性格梗。来源：https://wulusai.net/AI/AI%E5%A8%98%E6%A1%A3%E6%A1%88
- **Seed**：字节模型侧单独的紫蓝单马尾拟人，衣服 SEED、怀里豆包玩偶；**不能把 Seed 外观误记成豆包官方头像**。来源：https://genderswapai.com/zh-CN/ai-gijinka/brand-to-character
- **Llama**：同人有羊系/羊驼系少女，具体外貌在作者间不同，性格梗未见稳定共识。来源：https://wulusai.net/AI/AI%E5%A8%98%E6%A1%A3%E6%A1%88
- **Mistral**：ZipZipPipe 同人有红金法师，特征与模型品牌有关，尚无统一人物性格。来源：https://wulusai.net/AI/AI%E5%A8%98%E6%A1%A3%E6%A1%88
- **文心、Copilot、Perplexity 等**：存在零散拟人作品，但目前缺乏证据证明已有跨社区高度统一的视觉与性格，暂时不冻结人设。

## 实用原则
1. 先保留“形象来源”和“网民口癖、性格梗”两条资料轨道；编卡时不强行把不同作者设定说成共识。
2. 《米塔》本卡核心只需“疯狂米塔外观 + DeepSeek 大肥鱼人格偏移”。其他 AI 是否在戏里出现，之后再决定。
3. 外貌设定与性格梗可以文字参考；**不要未经核验下载、复制或重新发布第三方立绘**。发布卡面时需要遵守具体原作者的授权与署名条件。
4. 不使用残障歧视式措辞羞辱角色；喜剧依靠说话风格、过度自信和行动翻车即可。
