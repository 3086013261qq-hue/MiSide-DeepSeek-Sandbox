# 006｜第二批AI娘本体外貌与米塔记忆配饰 v1.0
日期：2026-11-09。材料来自用户在本聊天亲自提供的**10张塔罗牌立绘**（编号按发送顺序）；人物归属采用用户亲自纠正的答案及此前部分已识别的牌面线索。这里记录的是**画面可见的外貌**，不是官方形象，不虚构“全网统一性格”。本轮**不新增语言风格调查**，不改变首批12位分配。

## 规则
- **普通视角**：原作米塔的脸、头发、基本服装、版本特征与身体比例保持原有样子。第二批每位分到**一件细小而明确**的二创专属配饰，仅作为看人认人的视觉记忆点。不得把AI本体的翅膀、兽耳、发色、尾巴、衣服整体替换给米塔。
- **戴上「绒绒和多娜的玩具眼镜」**（黑框、大鼻子、假胡子）：镜片内才显示下述AI本体同人造型；摘下恢复米塔外观及小配饰。
- **原作仅有名称、没有明确全身立绘的米塔**：本卡允许她们正常参与轻喜剧；以**一般米塔的视觉母版+一件识别配饰**作为本同人卡的便捷想象，明确不是官方定稿。电话米塔等**原本就有特殊造型/媒介**的角色不可生造普通人形。
- 每位第二批米塔**只加一件指定配饰**；不另加徽章、披风、翅膀、头饰一整套。小配饰不是揭示AI本体的替代物。首批12位的样貌规则不变。

## 可执行的外貌模板
- 对于已有明确原作造型的米塔，**原本造型 + 上表唯一一件装饰**。
- 对于只在Wiki提到名字、缺少可证实的具体服装和发型的米塔，可用**常见米塔的蓝紫头发、红色上衣、蓝色百褶裙、红色长袜等基础视觉母版 + 表中唯一配饰**；在条目明确说明**这是本卡想象，不是游戏官方未公开的造型**。
- 不随意补身高体重、罩杯，不给未证实的米塔写“官方服装花纹”，也不让第二批配饰喧宾夺主。
- **电话米塔**以电话媒介形态活动；**故障米塔**等保持原作可辨认的特殊身形，用户指定的轻喜剧世界不会转为残酷剧情。
- 第一批12位配对与健康小米塔一律保持，**GPT不进扮演名单**，绒绒与多娜只在合照彩蛋里。
